**E-Commerce Sales Analytics (SQL)**

A relational database project simulating a small e-commerce business — customers, products, orders, payments, and reviews — built to demonstrate SQL skills from basic to intermediate level.

What's Inside:
Schema design: 7 normalized tables with primary/foreign keys, composite keys, and CHECK constraints
Sample data: realistic seed data with intentional edge cases (customers with no orders, unsold products, pending/cancelled orders)
Core queries: JOINs, GROUP BY/HAVING, correlated subqueries, CASE-based customer segmentation
Advanced concepts: window functions (RANK, LAG), CTEs, views, stored procedures, triggers, indexing
Files:
schema.sql — table definitions
seed.sql — sample data
queries.sql — all analysis queries

Built to practice modeling real business data and answering practical questions with SQL — customer segmentation, revenue by category, product performance, and month-over-month trends.
